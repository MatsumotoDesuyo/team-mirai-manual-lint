# B-TEXT-015 二重否定禁止

skill / CLI 共通プロンプト。

## 該当ガイドライン

§3 表現の簡潔化と明確化 / ダイレクトな肯定

> 二重否定（〜しないわけではない）を禁止し、ダイレクトな肯定表現を用いる。

`severity`: `WARN`

## 判定手順

本文段落から、**二重否定**を抽出する。

代表例:

| 二重否定 | 直接肯定 |
|---|---|
| 〜しないわけではない | 〜することもある / 〜である |
| 〜なくない | 〜である |
| 〜できないことはない | 〜できる場合もある |
| 〜ないとは言えない | 〜の可能性がある |
| 〜ないこともない | 〜することがある |
| 〜とは限らない | 〜の場合もある（文脈による） |
| 〜のないわけがない | 〜である |

## 除外基準

以下は対象外:
- **法令的記述・条文引用の二重否定**: 「〜しないことができない」（権利規定）等
- **修辞的な意図が明確な箇所**: 強調のための意図的な二重否定（例: 文脈で必須）
- **「とは限らない」の例外**: 全称否定を弱める用法は許容される場合あり。文脈で判断

## 出力フィールド

| フィールド | 内容 |
|---|---|
| `paragraphIndex` | 段落のインデックス |
| `snippet` | 該当文（30〜80 字、原文ママ） |
| `double_negation` | 二重否定表現の該当語句 |
| `direct_form` | 直接肯定表現への書き換え |
| `reason` | 短縮しても意味が変わらない理由 |
