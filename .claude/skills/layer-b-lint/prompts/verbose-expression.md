# B-TEXT-013 冗長表現

skill / CLI 共通プロンプト。

## 該当ガイドライン

§3 表現の簡潔化と明確化 / 文言の単純化

> 目的達成に不要な言葉を極限まで削る。
> 例：「〜することができる」等の冗長な表現を「〜できる」に短縮する。

`severity`: `WARN`

## 判定手順

本文段落から、**冗長な表現** を抽出する。

代表的な冗長パターン:

| 冗長表現 | 簡潔形 |
|---|---|
| 〜することができる | 〜できる |
| 〜することが可能である | 〜できる |
| 〜という形で | 〜として |
| 〜のような形で | 〜のように |
| 〜の場合がある | 〜することもある |
| 〜について | 〜は |
| 〜に関して | 〜は |
| 〜していく | 〜する |
| 〜していくこと | 〜すること |
| 〜の状態である | 〜である |
| 〜という事実がある | 〜である |
| 〜することとなる | 〜する |
| 〜する必要がある | 〜が必要 / 〜する |
| 〜のもとに行う | 〜で行う |

## 除外基準

以下は対象外:
- **文脈上必要な冗長**: 法令的記述で省略すると意味が変わる（例: 「〜することができる」と「〜できる」では権利規定として違いがある場合）
- **強調のための意図的な冗長**: 「絶対に〜することはできない」の「することは」が強調機能を持つ
- **置換不能な箇所**: 「〜が可能である」のような自然な代替形が無いケース

## 出力フィールド

| フィールド | 内容 |
|---|---|
| `paragraphIndex` | 段落のインデックス |
| `snippet` | 該当文（30〜80 字、原文ママ） |
| `original` | 冗長表現の該当語句 |
| `concise` | 短縮形 |
| `reason` | 短縮しても意味が変わらない理由 |
