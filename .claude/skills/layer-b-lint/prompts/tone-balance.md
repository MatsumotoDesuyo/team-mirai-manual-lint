# B-TONE-002 文章のトーン

skill / CLI 共通プロンプト。

## 該当ガイドライン

§1 チームみらいらしさの反映 / 文章のトーン

> - 固すぎず、親切、丁寧、やさしく、楽しい。守るべきルールについては厳格
> - 感情を強く刺激しすぎる表現にせず、落ち着いたトーンを維持
> - 簡潔で効率よく理解しやすい、わかりやすい表現

`severity`: `WARN`

## 判定手順

本文段落から、**トーンが不適切**な箇所を抽出する。

検出パターン:

| 問題類型 | 該当例 |
|---|---|
| 固すぎる | 漢語多用・公文書調・「〜せられたく候」のような古風表現（法令解説節は除く） |
| 砕けすぎ | 「やばい」「マジで」「〜じゃん」のような口語スラング |
| 煽情的 | 「絶対に〜！」連発、「衝撃の事実」のような扇動的表現、過剰な感嘆符 |
| 楽しさの欠如 | 全段落が淡々と禁止事項のみで、ガイドラインが求める「親切・やさしい」トーンが欠落（章レベルの判定） |

## 除外基準

以下は対象外:
- **法令解説節**: 厳格な記述は許容（「守るべきルールについては厳格」と明示）
- **安全に関わる強い注意喚起**: 「絶対に道路を塞がない」など
- **見出し**: 短い見出し自体は別判断
- **B-TONE-001 価値観違反で個別検出される内容**

## 判定方針

「主観的に固い/砕けすぎ」だけでは検出しない。**ガイドラインの基準と明らかにズレている**場合のみ。

## 出力フィールド

| `suggestion` | トーン調整後の書き換え案 |
| `reason` | 判定根拠 |
