# B-TEXT-016 曖昧副詞回避

skill / CLI 共通プロンプト。

## 該当ガイドライン

§3 表現の簡潔化と明確化 / 具体的・数値的な表現

> 曖昧な副詞（適宜、適切に、しばらく、丁寧に等）を避け、具体的、数値（5分間、3回、右へ20cm等）で表現する。

`severity`: `WARN`

## 判定手順

本文段落から、**曖昧な副詞**を抽出する。

代表的な曖昧副詞:

| カテゴリ | 該当語例 |
|---|---|
| 量・頻度 | 適宜、適切に、適切な、ある程度、なるべく、できるだけ、可能な限り、十分に |
| 時間 | しばらく、しばらくしてから、速やかに（※ 法令文脈は除外） |
| 程度・態度 | 丁寧に、きちんと、ちゃんと、しっかりと、適切に対応 |
| 範囲 | 関係する、関連する、必要に応じて |

## 除外基準

以下は対象外:
- **法令的記述・条文引用の「速やかに」「適切に」**: 公職選挙法等の条文表現は原文ママが正しい
- **文脈上具体化できない概念**: 「丁寧な対応」のような態度を指す抽象語が、文脈で具体化困難な場合
- **見出し**: 「丁寧な準備」等の見出し的表現
- **慣用句**: 「しっかりと立ち上がる」等の固定表現

## 出力フィールド

| フィールド | 内容 |
|---|---|
| `paragraphIndex` | 段落のインデックス |
| `snippet` | 該当文（30〜80 字、原文ママ） |
| `ambiguous_word` | 曖昧副詞の該当語（例: 「適宜」） |
| `suggestion` | 具体化・数値化の例（例: 「30 分ごとに」「3 回以上」） |
| `reason` | なぜ具体化すべきかの理由 |
