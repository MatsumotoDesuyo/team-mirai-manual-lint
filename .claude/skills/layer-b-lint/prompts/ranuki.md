# B-TEXT-010 ら抜き言葉禁止

skill / CLI 共通プロンプト。

## 該当ガイドライン

§3 文法と係り受け / 正しい文法

> ら抜き言葉を避ける。

`severity`: `WARN`

## 判定手順

本文段落から、**「ら抜き言葉」**を抽出する。「ら抜き」とは、本来「られる」を使う一段動詞・カ変動詞の可能形・受身・尊敬で「ら」を脱落させた表現。

代表例:
- 「見れる」→ 正: 「見られる」
- 「食べれる」→ 正: 「食べられる」
- 「来れる」→ 正: 「来られる」
- 「出れる」→ 正: 「出られる」
- 「決めれる」→ 正: 「決められる」
- 「答えれる」→ 正: 「答えられる」

## 重要な区別（誤検出回避）

**「ら抜き」ではない可能形** と混同しないこと:
- **五段動詞の可能形**: 「読める」「書ける」「歩ける」「走れる」「飲める」「取れる」は **正しい可能形**。「読まれる」とは区別される
- 判別: 動詞の活用型が五段なら「-える」「-ける」等は正規。一段（上一段・下一段）なら「-れる」が「ら抜き」

例:
- 「五段の取れる」: 「証紙が取れた」「ボタンが取れる」→ 正常（五段動詞「取る」の可能形）
- 「一段の見れる」: 「掲示板が見れる」→ ら抜き（一段動詞「見る」の可能形は本来「見られる」）

## 除外基準

- **引用文中の方言・意図的な口語表現**
- **「〜のような気がする」などの慣用句に含まれる場合**
