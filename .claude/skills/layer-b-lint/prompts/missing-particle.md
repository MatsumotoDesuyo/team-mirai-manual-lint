# B-TEXT-009 格助詞省略しない

skill / CLI 共通プロンプト。

## 該当ガイドライン

§3 文法と係り受け / 正しい文法

> 「は・が・を・に」などの格助詞を省略しない。

`severity`: `WARN`

## 判定手順

本文段落から、**格助詞「は・が・を・に・へ・と・から・まで・より・で」が省略されて意味が取りづらい**箇所を抽出する。

検出の典型例:
- 「ポスター貼ります」→ 「ポスターを貼ります」
- 「掲示板汚れているとき」→ 「掲示板が汚れているとき」
- 「写真撮影必須」→ 「写真の撮影は必須」

## 除外基準

以下は対象外:
- **体言止めの見出し・キャッチコピー**: 「準備するもの」「持ち物」など
- **名詞句で完結する箇条書き先頭**: 「ポスター: その日に貼る枚数」のような項目名
- **定型敬語**: 「ご確認ください」「お願いします」
- **複合語**: 「写真撮影」「掲示板設置」のような熟語化された無助詞表現

## 出力フィールド

| フィールド | 内容 |
|---|---|
| `paragraphIndex` | 段落のインデックス |
| `snippet` | 該当文（30〜80 字、原文ママ） |
| `missing_particle` | 省略されている格助詞（例: 「を」「が」） |
| `suggestion` | 助詞を補った書き換え |
| `reason` | なぜ補完すべきかの理由 |
