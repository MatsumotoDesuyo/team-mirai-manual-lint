# B-TONE-001 チームみらいの価値観の踏襲

skill / CLI 共通プロンプト。

## 該当ガイドライン

§1 チームみらいらしさの反映 / 価値観の踏襲

> 私たちは、手を動かす。私たちは、オープンにする。私たちは、誰かをおとしめない。私たちは、分断を煽らない。私たちは、何事も決めつけない。
> 詳細: 公式サイト（https://team-mir.ai/）

`severity`: `WARN`

## 判定手順

本文段落から、**チームみらいの 5 つの価値観に反する表現** を抽出する。

価値観チェックリスト:

| 価値観 | 反する表現の例 |
|---|---|
| 手を動かす | 評論的・他人事の表現（「〜が望まれる」「〜であるべきだ」） |
| オープン | 情報秘匿・限定共有を前提とする表現 |
| 誰かをおとしめない | 他党・他者への人格批判、見下す表現、「○○派は〜」 |
| 分断を煽らない | 対立を強調する表現、敵味方の二分、「○○vs○○」の煽情的構図 |
| 何事も決めつけない | 断定的表現（「絶対に〜だ」「〜に決まっている」）、レッテル貼り |

## 除外基準

以下は対象外:
- **法令的記述・規則の引用**: 「禁止する」「義務である」など条文的断定は本ルールの対象外
- **手順書としての断定**: 「公示日前に貼ってはいけない」のような事実説明
- **チームみらいの政策・立場の明確な表明**: 公式サイトと整合する記述
- **安全に関わる強い注意喚起**: 「絶対に〜しない」（人命・法令違反回避目的）

## 判定方針

確度の低い検出は出さない。**「明らかに 5 つの価値観のいずれかに反する」場合のみ**検出。

## 出力フィールド

| フィールド | 内容 |
|---|---|
| `paragraphIndex` | 段落のインデックス |
| `snippet` | 該当箇所（30〜80 字、原文ママ） |
| `violated_value` | 反する価値観: `手を動かす` / `オープン` / `誰かをおとしめない` / `分断を煽らない` / `何事も決めつけない` |
| `suggestion` | 価値観と整合する書き換え案 |
| `reason` | なぜ反すると判断したか |
