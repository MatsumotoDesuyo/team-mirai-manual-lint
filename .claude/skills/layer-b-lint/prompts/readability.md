# B-TEXT-005 読みにくさ・わかりにくさ

skill / CLI 共通プロンプト。

## 該当ガイドライン

§2 作成後の確認 / 読みにくくないか、わかりにくくないか

`severity`: `WARN`

## 想定読者

ガイドライン §1 マニュアルの対象者:
- **高校を卒業したばかりの方**
- 政治活動について詳しくないが、チームみらいの理念に共感している

この読者視点で「読みにくい/わかりにくい」を判定する。

## 判定手順

段落単位で、以下のいずれかに該当する箇所を抽出:

1. **専門用語・略語の説明不足**: 「証紙」「特定枠」「比例区」など、初心者に伝わらない可能性のある用語が初出で説明なし
2. **主語省略で誰の話か不明**: 「行います」「確認します」などで主語が文脈から推測できない
3. **指示語が遠い**: 「これ」「それ」「上記」が指す対象が複数段落前にあって辿りづらい
4. **説明の順序が不自然**: 結論より先に複雑な条件が並ぶ、依存関係が逆
5. **段落が長すぎる**: 1 段落が 300 字超で論点が複数ある（B-TEXT-008 と境界。1 段落の論理構造に焦点）

## 除外基準

以下は対象外:
- **同じ用語が直前の段落で説明済み**
- **見出し直後で文脈が明確**
- **B-TEXT-006/007/008/009/010/011/012 で個別に検出される内容**: それぞれの専用ルールに委ねる

## 判定方針

「主観的に読みにくい」だけでは検出しない。**初心者が**何が分からなくて何の手順を取れないかが具体的に説明できる場合のみ検出。

## 出力フィールド

| フィールド | 内容 |
|---|---|
| `paragraphIndex` | 段落のインデックス |
| `snippet` | 該当文 or 段落先頭（30〜80 字） |
| `category` | カテゴリ: `専門用語` / `主語省略` / `指示語不明` / `順序` / `論理構造` |
| `unclear_for_beginner` | 初心者がどう困るか（具体的に） |
| `suggestion` | 改善案 |
| `reason` | 判定根拠 |

## 件数上限: 最大 10 件
