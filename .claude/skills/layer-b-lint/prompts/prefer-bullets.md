# B-TEXT-008 長文回避・箇条書き推奨

skill / CLI 共通プロンプト。

## 該当ガイドライン

§3 文章の基本 / 長文回避

> 長文は避け、短い概要文と箇条書きの組み合わせでの表現を心がけてください。

`severity`: `WARN`

## 判定手順

本文段落から、**箇条書きに分解できそうな長文段落** を抽出する。

検出パターン:
- **並列要素が文章内で連結されている**: 「A は〜であり、B は〜であり、C は〜である」のような列挙が文章で書かれている（3 つ以上）
- **手順が文章で書かれている**: 「まず〜し、次に〜し、最後に〜する」のような連続手順
- **対照が文章で書かれている**: 「選挙期間中は〜だが、選挙期間外は〜である」のような対照（表化推奨）

## 除外基準

以下は対象外:
- **2 要素以下の並列**: 箇条書きにする必要なし
- **既に箇条書き形式の段落**
- **見出しの直後にある「概要文」**: ガイドライン推奨の「短い概要文」に相当する箇所
- **法令的記述で原文ママ必要**
- **B-TEXT-007（一文長）で個別に検出される単純な長文**: 本ルールは「分割」ではなく「箇条書き化」を提案

## 出力フィールド

| フィールド | 内容 |
|---|---|
| `paragraphIndex` | 段落のインデックス |
| `snippet` | 該当段落の冒頭（30〜80 字） |
| `pattern` | 検出パターン: `並列` / `手順` / `対照` |
| `extracted_items` | 箇条書き化したときの項目リスト（配列、各 1 行） |
| `suggestion` | 箇条書き化後の Markdown 形式案（短く） |
| `reason` | 判定根拠 |

## 件数上限: 最大 10 件
