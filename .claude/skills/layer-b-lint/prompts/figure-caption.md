# B-TEXT-018 図表補足説明

skill / CLI 共通プロンプト。

## 該当ガイドライン

§3 情報設計 / 図表の補足

> 図や表は、何を伝えたいのかがわかるように説明文を入れる。

`severity`: `WARN`

## 判定手順

本文中の **図・表に対する補足説明（キャプション・前置き）が欠落** している箇所を抽出する。

判定対象:
- Markdown / Doc 上で「[画像]」「画像」「写真」「図」「表」のような表現で言及されている箇所
- 表（テーブル）の前後に説明文がない箇所
- 画像が挿入されているが、その意図・読み取り方の説明がない箇所

## 除外基準

以下は対象外:
- **直前または直後の段落で図表の説明が完結している場合**
- **見出しが図表の内容を端的に示している場合**
- **複数の図表が連続するチャート的な構成で、各個別キャプションがなくても意図が明確な場合**
- **Doc 本文だけで図表位置を判定できない**: skill / CLI からは画像オブジェクトの位置情報が取れない場合、テキスト中の「図」「表」「画像」キーワードベースの判定に限定

## 重要

本ルールは判定が難しい。テキストだけで「キャプションがない」を判定すると過剰検出になりやすい。**「明確に図表への言及があるが説明が完全に欠落している」場合のみ**検出する。

## 出力フィールド

| フィールド | 内容 |
|---|---|
| `paragraphIndex` | 段落のインデックス |
| `snippet` | 該当箇所（30〜80 字） |
| `figure_reference` | 言及されている図表（例: 「上の表」「下記の図」） |
| `missing_aspect` | 不足している説明の側面（例: 「何を比較しているか」「数値の単位」） |
| `suggestion` | 補足説明の追加案 |
| `reason` | 判定根拠 |
