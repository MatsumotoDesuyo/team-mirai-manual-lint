# B-TEXT-006 1文1トピック

skill / CLI 共通プロンプト。

## 該当ガイドライン

§3 文章の基本 / 1文1トピックの原則

> 1つの文には1つのトピックのみを記述する。

`severity`: `WARN`

## 判定手順

本文段落から、**1 文に複数のトピックが混在している**箇所を抽出する。「トピック」は「主題となる行為・概念」のこと。1 つの文で 2 つ以上の独立した話題を扱っている場合に検出。

## 除外基準

以下は対象外:
- **並列箇条書きの 1 文**: 「〜と〜と〜」のように接続詞で並列する列挙
- **主語が同じで述語のみ並ぶ複文**: 「彼は走り、跳び、踊った」のように同一主語の連続行為
- **引用文・条文**: 法令・規則の原文ママ引用
- **目的と手段が密接な複文**: 「写真を撮って、Slack に投稿する」のような自然な動作連鎖

## 出力フィールド

| フィールド | 内容 |
|---|---|
| `paragraphIndex` | 段落のインデックス（0 始まり） |
| `snippet` | 該当文を原文ママで（30〜80 字） |
| `topics` | 検出された複数トピックの簡潔な要約（配列、各 10〜30 字） |
| `suggestion` | 分割案（2 つ以上の文に分けた書き換え） |
| `reason` | なぜ分割すべきかの短い理由 |

## 件数上限: 最大 10 件

該当なしの場合は空配列。

## CLI 経由は JSON のみで返す（手順は SKILL.md の Step 4 を参照）。
