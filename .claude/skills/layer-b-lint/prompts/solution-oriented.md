# B-TEXT-017 解決志向のメッセージ

skill / CLI 共通プロンプト。

## 該当ガイドライン

§3 表現の簡潔化と明確化 / 解決志向のメッセージ

> 注意書きでは、問題だけでなく、推奨すべきことも具体的に指示する。

`severity`: `WARN`

## 判定手順

本文段落から、**「禁止・問題提示のみ」で「では何をすべきか」が示されていない注意書き** を抽出する。

検出パターン:
- 「〜は禁止」とだけ書かれて、「代わりにどうするか」「合法な範囲」が書かれていない
- 「〜は危険」とだけ書かれて、「危険を避けるためにどう行動するか」が書かれていない
- 「〜にならないように」とだけ書かれて、具体的な手順がない

例:
- ❌ NG: 「ポスターを傷つけないでください」
- ⭕ OK: 「ポスターは折り目をつけずに、貼付台紙の端から丁寧に剥がして使用してください」

## 除外基準

以下は対象外:
- **法令的禁止事項**: 法令引用で「禁止」のみ記載される条文（解決策が法令の範囲外）
- **直前または直後の段落で推奨行動が示されている**: 同一論点で問題と解決策が分かれている場合
- **章タイトル・短い見出し**: 「禁止事項」のような見出し自体
- **明確な指示が文脈で自明な場合**: 「ゴミは持ち帰る」のように、行動が一行で完結している場合

## 出力フィールド

| フィールド | 内容 |
|---|---|
| `paragraphIndex` | 段落のインデックス |
| `snippet` | 該当箇所（30〜80 字、原文ママ） |
| `problem_only` | 提示されている問題・禁止事項 |
| `missing_solution` | 不足している推奨行動の方向性 |
| `suggestion` | 解決策を含めた書き換え案 |
| `reason` | 判定根拠 |
