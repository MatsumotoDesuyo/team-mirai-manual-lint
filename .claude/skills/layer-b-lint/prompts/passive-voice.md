# B-TEXT-014 受動態回避

このファイルは skill (`/layer-b-lint`) と CLI ([cli/src/handlers/text.js](../../../../cli/src/handlers/text.js)) の両方から参照される **共通プロンプト** です。判定基準を一箇所に集約することで、運用経路によって判定がブレないようにします。

---

## 該当ガイドライン

§3 表現の簡潔化と明確化 / 能動態の使用

> 受動態（〜される）を避け、能動態（〜する）で記述して「誰が何をするか」を明確にする。

`severity`: `WARN`（Layer B は助言、ERROR は出さない）

## 判定手順

対象 Doc の本文段落から、**改善すべき受動態**が使われている箇所を抽出する。

## 除外基準（誤検出回避）

以下のパターンは **対象外** とする。誤検出を出さない:

- **法令的記述・規則**: 「禁止されています」「許可されています」「定められている」「規定されている」など。法令文の引用や引用に近い箇条は能動化すると意味が変わる
- **受身の主語が主題**: 「通行人に声をかけられた」のように、読み手（受け手）の体験が主題で能動化すると焦点がずれる場合
- **慣用句・定型句**: 「議員と呼ばれる」「と言われている」「決められている」「知られている」など、自然な日本語として定着している表現
- **無生物主語の受動**: 「写真はその場で撮られ、共有される」のように行為者が文脈から自明で、能動化が冗長になる場合
- **見出し・タイトル**: ガイドライン §3 の対象は本文。見出しは Layer A の別ルールに任せる

## 出力フィールド

各検出箇所は以下のフィールドを持つ:

| フィールド | 内容 |
|---|---|
| `paragraphIndex` | 段落のインデックス（Body 走査順、0 始まり） |
| `snippet` | 受動態を含む 30〜80 字程度の引用（**原文ママ**で） |
| `passive_phrase` | 受動態の該当語句（例: 「撤去されます」「定められている」） |
| `suggestion` | 能動態への書き換え案（短い 1 行） |
| `reason` | なぜ能動化すべきかの短い理由（除外基準にあてはまらない理由） |

## 件数上限

**最大 15 件**まで、重要度の高い順（自然さで除外しきれず、改善効果が大きいもの順）に絞る。

## 出力ゼロのケース

受動態が見つからない、もしくは全て除外基準に該当する場合は、**空の findings 配列**を返す。無理に検出を生成しない。

## skill / CLI それぞれの出力形式

### skill 経由（対話）

人間に説明する形で各 Finding を提示。ユーザーが「JSON で」と指定したら JSON 形式に切り替え。

### CLI 経由（cli/）

必ず JSON のみで返す:

```json
{
  "findings": [
    {
      "paragraphIndex": 5,
      "snippet": "...",
      "passive_phrase": "...",
      "suggestion": "...",
      "reason": "..."
    }
  ]
}
```
