# B-TEXT-004 誤字脱字

skill / CLI 共通プロンプト。

## 該当ガイドライン

§2 作成後の確認 / 誤字、脱字がないか

`severity`: `WARN`

## 判定手順

本文段落から、**誤字・脱字・送り仮名の誤り** を抽出する。

代表例:
- 漢字の誤り: 「異なる」を「違なる」、「対応」を「対応」（誤変換）
- 送り仮名の誤り: 「行なう」/「行う」、「表わす」/「表す」（一般的には送り仮名少ない形を推奨）
- 助詞・語句の脱字: 「貼り、る」「あた配る」
- 同音異義語の取り違え: 「進める/勧める」「指す/差す」「治す/直す」「効く/聞く」
- 敬語の誤用: 「ご存知」（正は「ご存じ」）

## 除外基準

以下は対象外:
- **固有名詞・人名・地名**: 表記揺れがあっても誤りとは限らない
- **専門用語**: 業界・分野固有の表記
- **引用文の原文ママ**
- **意図的な口語・方言表現**

## 判定方針

確度が低い指摘は出さない。**「ほぼ確実に誤字」と判定できるものに限る**。読み手の解釈で揺れる可能性があるものは judgment 見送り。

## 出力フィールド

| フィールド | 内容 |
|---|---|
| `paragraphIndex` | 段落のインデックス |
| `snippet` | 該当文（30〜80 字、原文ママ） |
| `typo` | 誤りの該当語句 |
| `correction` | 正しい表記 |
| `category` | カテゴリ: `誤変換` / `送り仮名` / `脱字` / `同音異義` / `敬語誤用` |
| `reason` | 判定根拠 |

## 件数上限: 最大 15 件
