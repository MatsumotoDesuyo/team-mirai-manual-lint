# B-TEXT-003 用語統一

skill / CLI 共通プロンプト。

## 該当ガイドライン

§2 表記ゆれ防止ルール / 用語の統一

> 複数人で執筆しても表記がばらつかないよう、必須・推奨ルールを用意しています。

`severity`: `WARN`

## 用語集スプレッドシート参照（必須）

判定基準は **校正用ルール・用語集スプレッドシート** に集約されている:

- **skill 経由**: Google Drive MCP で `1YhKZ48Cyel-_zq8Jcj580w0wViUE7KMX1u-651IEdp0` を取得。用語対照タブ（「正/誤」「推奨/非推奨」等）を全て参照
- **CLI 経由**: runner.js が用語集データを user prompt に展開

## 判定手順

本文段落から、**用語集で「非推奨／誤」と分類されている表記** を抽出し、推奨表記への置き換えを提案する。

典型的な対象パターン（用語集に依存）:
- 表記ゆれ: 「サポーター」/「支援者」、「ボランティア」/「ボランティアー」など
- 推奨用語の不使用: 用語集が「推奨」する表現を使っていない
- 非推奨用語の使用: 用語集が「使用しない」と指定する用語

## 除外基準

以下は対象外:
- **固有名詞・人名・組織名**: 表記が固有名詞として確定
- **引用文の原文ママ**
- **同綴り異義語の文脈無視置換は禁止**: 「直す/治す」「指す/差す」のような同綴りは、用語集の対照表だけで機械的に置換しない。意味判定して該当文脈のみ置換提案
- **見出し**: 短い見出しは別判断

## 重要

用語集にない表記を「誤り」と判定しない。**用語集に明示的に対照ルールがあるもののみ**検出する。
判定確度が低い指摘は出さない（過剰検出を避ける）。

## 出力フィールド

| フィールド | 内容 |
|---|---|
| `paragraphIndex` | 段落のインデックス |
| `snippet` | 該当文（30〜80 字、原文ママ） |
| `non_recommended_term` | 検出された非推奨表記 |
| `recommended_term` | 用語集が推奨する表記 |
| `glossary_source` | 用語集のどのシート・行に基づく判定か（例: 「サポーター用語タブ 12 行目」） |
| `reason` | 判定根拠 |
