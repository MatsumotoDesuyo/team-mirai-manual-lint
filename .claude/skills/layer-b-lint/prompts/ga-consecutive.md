# B-TEXT-011 「が」連続使用回避

skill / CLI 共通プロンプト。

## 該当ガイドライン

§3 文法と係り受け / 助詞「が」の連続使用を避ける

`severity`: `WARN`

## 判定手順

本文段落から、**1 文の中に助詞「が」が複数回出現**して読みにくい箇所を抽出する。

特に問題となるパターン:
- **逆接「が」と主格「が」の混在**: 「Aは〜だが、Bが〜する」
- **接続助詞「が」が連続**: 「〜だが、〜だが、〜」
- **長文の中で「が」が 3 回以上**

## 除外基準

以下は対象外:
- **並列主語のみの複数「が」**: 「A が〜し、B が〜する」（接続詞「が」を含まない、主格のみ）
- **2 回程度で意味が明確な短文**: 「私が言ったが、彼は理解した」（30 字以下で意味曖昧でない）

## 出力フィールド

| フィールド | 内容 |
|---|---|
| `paragraphIndex` | 段落のインデックス |
| `snippet` | 該当文（30〜80 字、原文ママ） |
| `ga_count` | 1 文中の「が」出現数 |
| `ga_types` | 各「が」の種別（"主格" / "接続助詞" / "対象格"） |
| `suggestion` | 文分割案 or 書き換え案 |
| `reason` | 読みにくさの理由 |

## 件数上限: 最大 10 件
